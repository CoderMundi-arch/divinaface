# Derley Silva — site estático

Site recriado em HTML, CSS e JavaScript, inspirado no layout visual aprovado.

## Como visualizar
Abra `index.html` no navegador ou rode `python -m http.server 8000` na pasta.

## Como publicar no GitHub Pages
Envie `index.html`, `style.css`, `script.js` e a pasta `assets/` para a raiz de um repositório público. Em Settings > Pages selecione Deploy from a branch, `main`, `/ (root)`.

## Imagens
As imagens são recortes obtidos da captura de tela anterior, portanto algumas podem ter resolução limitada. Substitua os arquivos em `assets/` por fotografias originais preservando os mesmos nomes.

## Agendamento
Os botões de serviços e agendamento apontam para `https://bit.ly/3rEdPdU`, link encontrado no material de referência. Confirme se continua sendo o destino desejado antes de publicar.

## Fontes
Italiana e DM Sans carregadas via Google Fonts; se estiver offline, o site usa fontes de fallback.
